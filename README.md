# NovaCart SQL Lab

NovaCart SQL Lab is a hands-on SQL database project designed to bring together the SQL concepts you have learned in one complete database workflow.

## Project Journey

You will work through the project in this order:

1. Understand the Business Requirements
2. Design the Conceptual ERD
3. Create the Relational Mapping
4. Build the Database using DDL
5. Insert and prepare the dataset
6. Solve the SQL Missions
7. Validate your final work

## Student Package

All student materials are inside:

`01_Student_Package/`

Files:

- `01_NovaCart_SQL_Lab.pdf` — Project guide and requirements
- `02_NovaCart_SQL_Hints.pdf` — Hints and guidance
- `03_NovaCart_SQL_Questions.sql` — SQL assignment questions

## Important

This repository contains the student materials only.

You are expected to build your own:

- ERD
- Relational Mapping
- DDL
- Insert Data
- SQL Solutions

Do not look for completed solutions in this repository.

## Recommended Workflow

Read the project guide first.

Then work through the project step by step:

Business Requirements
→ ERD
→ Relational Mapping
→ DDL
→ Insert Data
→ SQL Missions
→ Validation

Try to solve each task yourself before using the provided hints.
